【脚本改造】
  1. 导入配置
     from src.config import init_config
     config = init_config()
  
  2. 替换参数
     OLD: LEARNING_RATE = 0.001
     NEW: LEARNING_RATE = config.get_float("training.learning_rate")
  
  3. 测试运行
     python 2_train_model.py
     ✓ 成功！

【日常使用】
  想改学习率？
     ↓
  编辑 config.yaml (第 23 行)
     ↓
  learning_rate: 0.0005
     ↓
  所有脚本自动生效！


【配置查询流程】
  需要某个参数
     ↓
  查看 config.yaml 或 CONFIG_QUICK_REF.md
     ↓
  找到配置键，如 "training.learning_rate"
     ↓
  在脚本中使用: config.get_float("training.learning_rate")
     ↓
  完成！
