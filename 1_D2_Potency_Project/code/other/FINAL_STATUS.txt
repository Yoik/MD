================================================================================
                            核心功能
================================================================================

【三层权重机制】✅
  final_weight = ELF_weight × Angle_Decay × Distance_Decay
  
  1. ELF权重: 电子密度 (0-1范围)
  2. 角度衰减: exp(-(|θ-90°|/30°)²) → 奖励T-stacking
  3. 距离衰减: exp(-(d/2.0Å)²) → 奖励接近平面

【相互作用强度量化】✅
  - Strength_389: Phe389相互作用强度 (0-1)
  - Strength_390: Phe390相互作用强度 (0-1)
  - Strength_Combined: 综合相互作用强度 (0-1)
  - Quality_Score: 贡献均匀性评分 (0-1)
  - Major_Contributor: 主要贡献碳 (C1-C6)

【自动聚合功能】✅

================================================================================
                            相互作用强度解释
================================================================================

Strength_Combined 范围: [0, 1]

0.85-1.00  ★★★★★  优秀
  → 配体与Phe呈完美T-stacking
  → 多数碳接近90°且接近平面
  → 高度可靠的相互作用

0.60-0.85  ★★★★   良好
  → 配体与Phe呈良好T-stacking
  → 部分碳偏离，但整体方向正确
  → 强相互作用存在

0.35-0.60  ★★★    一般
  → 配体与Phe呈一般相互作用
  → 多个碳偏离90°，角度分散
  → 中等强度相互作用

0.00-0.35  ★★     较差
  → 配体与Phe无典型T-stacking
  → 大部分碳角度和距离不优
  → 弱相互作用或无相互作用
