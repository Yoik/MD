## 🔄 三层验证方法

### 1️⃣ Leave-One-Out (LOO) ⭐ 最严格
```
7个样本 → 循环7次
每次用6个训练，1个测试
✅ LOO R² = -0.2106 (Random Forest)
```

### 2️⃣ K-Fold (3-fold) 平衡选择
```
7个样本 → 分成3折
轮流使用1/3作为测试
✅ K-Fold R² = -0.2147
```

### 3️⃣ Hold-Out (25%) 简单基线
```
7个样本 → 5个训练，2个测试
⚠️ 结果不稳定 (R² = -4.04)
```

## ⚠️ 为什么R²为负?

**原因**:
1. 样本太少 (7个) vs 特征太多 (9个)
2. 特征未能捕捉效能的关键信息
3. 高维诅咒 + 随机噪声放大

**解读**:
- R² = -0.21 **不是**模型坏
- 而是说明 **数据本身不足以**建立可靠的回归关系
- MD分析的这些特征 **可能不是** 效能的强预测因子
