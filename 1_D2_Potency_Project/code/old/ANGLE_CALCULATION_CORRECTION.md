# 正确的角度计算说明

## 问题修正

之前的角度计算有误，现在已修正为：

### 旧方法（错误）❌
- 计算每个碳的"局部平面"与配体"整体平面"的夹角
- 这个角度不能直接反映碳原子与Phe环平面的关系

### 新方法（正确）✓
- **计算每个碳原子指向Phe质心的向量** 与 **Phe环平面法向量** 的夹角
- 这个角度直接反映该碳原子以何种方式接近Phe环

---

## 物理含义

### 角度的含义

```
配体碳 C
    │
    │ 向量 (C → Phe质心)
    │
    ▼
  Phe质心
   ╱ ╲
  ╱   ╲ Phe平面（6个碳原子）
```

**角度 θ** = 该向量与 **Phe平面法向量** 的夹角

| 角度 | 名称 | 含义 | 贡献权重 |
|------|------|------|---------|
| 0° | 平行 | 碳平行于Phe平面，无法有效接触 | 极弱 |
| 45° | 倾斜 | 碳以某个角度接近 | 中等 |
| **90°** | **垂直（T型）** | **碳垂直于Phe平面，完美T型堆积** | **最强** |
| 135° | 倾斜 | 碳以另一个角度接近 | 中等 |
| 180° | 平行 | 碳平行于Phe平面，无法有效接触 | 极弱 |

### T型堆积（π-π相互作用）

```
配体平面        Phe平面
  ⊕             ○ ○
  ⊕        ○ ○ ○   ○
  ⊕             ○ ○
               (俯视)

完美T型：配体平面垂直于Phe平面，碳指向Phe中心
```

## 衰减因子计算

### 公式
$$\text{角度衰减因子} = \exp\left(-\left(\frac{|\theta - 90°|}{30°}\right)^2\right)$$

### 示例

```
偏离角度    衰减因子    质量
±0°  (90°)    1.000    ✓✓✓ 完美T型
±5°  (85/95°) 0.972    ✓✓  非常好
±10° (80/100°)0.895    ✓   很好
±15° (75/105°)0.780    ✓   不错
±30° (60/120°)0.368    △   可以接受
±45° (45/135°)0.104    ✗   很差
±60° (30/150°)0.008    ✗   几乎无贡献
```

## CSV输出中的新列

### 时间序列文件
```
Time,Replica,Global_Angle,...,C1_Angle_to_Phe389,C2_Angle_to_Phe389,...,C6_Angle_to_Phe389
                                               ↑
                         每个碳与389平面的夹角（度数）
```

每一帧都会输出：
- `C1_Angle_to_Phe389` ~ `C6_Angle_to_Phe389`: 配体6个碳与Phe389平面的夹角
- `C1_Angle_to_Phe390` ~ `C6_Angle_to_Phe390`: 配体6个碳与Phe390平面的夹角

### 调试输出示例

```
Phe389 最大贡献原子: C1, ELF权重=0.850, 与平面角度=88.5°, 角衰减=0.995, 距离衰减=0.939, 距离=4.50Å
```

这表示：
- **与平面角度=88.5°** → 非常接近完美T型（90°），偏离仅1.5°
- **角衰减=0.995** → 几乎没有因为角度而损失权重

## 完整的三层加权机制

$$\text{Combined Weight} = \text{ELF Weight} \times \text{Angle Decay} \times \text{Distance Decay}$$

| 层次 | 参数 | 含义 |
|------|------|------|
| 1️⃣ | ELF Weight | 电子云密度强弱 |
| 2️⃣ | Angle Decay | 与T型堆积(90°)的匹配度 |
| 3️⃣ | Distance Decay | 离Phe平面的接近程度 |

### 最终加权平均距离
$$d_{\text{weighted}} = \frac{\sum_{i=1}^{6} d_i \times w_i \times a_i \times b_i}{\sum_{i=1}^{6} w_i \times a_i \times b_i}$$

## 使用建议

1. **分析单个帧的结果**
   - 查看 `C*_Angle_to_Phe389/390` 列
   - 如果大部分碳都在 80-100° 范围内 → 好的T型接触

2. **分析轨迹统计**
   - 生成的 CSV 文件中查看平均值
   - 比较不同配体的 `Dist_Phe*_Weighted_Mean` 值
   - 考虑角度信息理解结果差异

3. **诊断对接问题**
   - 如果 Weighted Distance 远大于 Geo Distance
   - 检查 `C*_Angle_to_Phe*` 列 → 角度不好
   - 查看 print 输出中的角衰减因子 → 确认问题
