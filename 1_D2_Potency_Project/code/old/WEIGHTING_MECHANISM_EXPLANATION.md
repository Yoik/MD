# 三层加权机制说明

## 核心改进

在计算**电子加权平均距离**时，现在综合考虑三个因素：

### 1️⃣ ELF权重 (w) - 电子云密度
- **含义**: 从ELF立方体文件中提取的每个碳原子的电子密度积分
- **范围**: 0 ~ 1（归一化到最大值）
- **解释**: 权重越大 → 电子云越强 → 与Phe环π电子相互作用越强

### 2️⃣ 角度衰减因子 - T型接触匹配度
- **计算**: 每个碳原子与相邻两碳定义的局部平面 vs 配体整体平面的夹角
- **公式**: `decay = exp(-(deviation/30°)²)` 其中 deviation = |angle - 90°|
- **特点**:
  - 完美T型堆积 (偏离 < 10°) → 衰减 ≈ 1.0 ✓
  - 偏离 30° → 衰减 ≈ 0.37
  - 偏离 45° → 衰减 ≈ 0.03
- **含义**: 违反T型堆积越严重，该原子贡献权重越弱

### 3️⃣ 距离衰减因子 - 空间接近度
- **计算**: 每个碳原子到Phe环平面的垂直距离（利用平面法向量）
- **公式**: `decay = exp(-(distance/2.0Å)²)`
- **特点**:
  - 接近平面 (< 1Å) → 衰减 ≈ 1.0 ✓
  - 距离 2Å → 衰减 ≈ 0.37
  - 距离 3.5Å → 衰减 ≈ 0.01
- **含义**: 离Phe环平面越远，该原子贡献权重越弱

## 加权平均距离计算

$$\text{Weighted Avg Distance} = \frac{\sum_{i=1}^{6} d_i \times w_i \times a_i \times b_i}{\sum_{i=1}^{6} w_i \times a_i \times b_i}$$

其中：
- $d_i$ = 第i个碳到Phe质心的距离
- $w_i$ = ELF权重
- $a_i$ = 角度衰减因子
- $b_i$ = 距离衰减因子

## 实际意义

这个加权平均距离能够反映：

| 情况 | 权重 | 解释 |
|------|------|------|
| 高ELF + 完美T型 + 接近平面 | ✓✓✓ | **最优贡献** - 强π-π相互作用 + 理想几何 |
| 高ELF + 良好T型 + 中等距离 | ✓✓ | **显著贡献** - 强电子 + 良好几何 |
| 高ELF + 差T型 + 远离平面 | ✗ | **几乎不贡献** - 即使电子强也无法有效接触 |
| 低ELF + 完美T型 + 接近平面 | ✓ | **微弱贡献** - 几何优但电子弱 |

## 输出说明

在时间序列文件和统计文件中，新增以下列：

- **Dist_Phe389_Geo**: 纯几何距离（质心对质心）
- **Dist_Phe389_Weighted**: 三层加权后的平均距离 ← **推荐使用**
- **AngDev_Phe389**: Phe389平面与配体平面的角度偏离
- **Angle_Decay_Mean**: 平均角衰减因子（用于诊断）

这表示C1原子：

- 与T型堆积很接近（偏离≈5°，衰减97.3%）
- 离Phe平面很近（≈0.5Å，衰减93.9%）
- 综合贡献权重最高

## 对比优势

| 方法 | 优点 | 缺点 |
|------|------|------|
| **纯几何距离** | 简单快速 | 忽视电子和几何匹配 |
| **ELF权重仅** | 考虑电子 | 忽视几何和距离 |
| **ELF+角度** | 考虑π-π相互作用 | 忽视空间接近度 |
| **ELF+距离** | 考虑电子和空间 | 忽视T型堆积 |
| **ELF+角度+距离** | ✓ 完整物理图像 | 稍复杂但更准确 |

## 参考值

高效结合的特征：
- **ELF权重**: 0.7-1.0 (强电子云)
- **角度衰减**: > 0.8 (接近T型: ±10°以内)
- **距离衰减**: > 0.8 (接近平面: < 1.2Å)
- **最终加权平均距离**: 通常 4.3-4.7Å (取决于具体结构)
